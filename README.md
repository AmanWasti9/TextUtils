# Text Utils
Text Utils is a web application developed using React JS for versatile text manipulation. It offers various text processing features such as text formatting, space removal, case conversion, Lorem Ipsum generation, and word counting.

## Features
- Text Formatting: Easily format your text to improve readability.
- Space Removal: Remove extra spaces from your text with a single click.
- Case Conversion: Convert text to uppercase, lowercase, capitalize each word, or sentence case.
- Lorem Ipsum Generation: Generate dummy text for testing purposes.
- Word Count: Count the number of words in your input text.

### Getting Started
1. Clone the repository:
```bash
git clone https://github.com/AmanWasti9/TextUtils.git
```
2. Change to the project directory:
```bash
cd TextUtils
```
3. Install dependencies:
```bash
npm install
```
4. Start the development server:
```bash
npm start
```

### Usage
1. Open your web browser and navigate to http://localhost:3000.
2. Use the input area to enter or paste your text.
3. Utilize the various buttons and options to manipulate your text as needed.

### Technologies Used
- React JS: Frontend framework for building the user interface.
- HTML: Markup language for structuring the application.
- CSS: Styling language for designing the application.
